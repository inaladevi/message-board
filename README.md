# Mini Message Board

A message board built with Node.js, Express, and EJS.

## Live Demo

🔗 [Click here to view the live app](https://message-board-8vvr.onrender.com)

## Features

- View all messages
- Create a new message
- View individual message details
- Server-side rendering with EJS
- Responsive styling with a midnight pastel arcade theme
- View expanded user profile data (email, age, and bio)
- Search through entries by username handle or email address

## Built With

- Node.js
- Express
- EJS
- HTML
- CSS

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the app locally

```bash
node --watch app.js
```
